# ConsoleGameStore

ASP.NET Core MVC application for a console game store.

## Stack

- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- Session
- .NET 8

## Included

- game catalog
- search and filters
- game details
- add to cart
- quantity update
- remove from cart
- clear cart
- initial SQLite data
- saved data model diagrams

## Run

Open `ConsoleGameStore.sln` in Visual Studio or open the folder and run the project.

The SQLite database file `consolegamestore.db` is created automatically on the first start.

The cart is stored in the current session and is not written to the database.
